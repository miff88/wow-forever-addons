# Target Arrow

**Find your target in any crowd.** Target Arrow puts a bobbing arrow above your target's nameplate, so you can pick it out instantly in a big pull, a busy city or a battleground.

Made for **World of Warcraft: Forever**. Works on every class.

## Features
- A clear arrow above your current target's nameplate that follows you every time you change target.
- Gentle bobbing animation so it catches your eye, or keep it still.
- Five colours: red, yellow, green, blue and white.
- Adjustable size and height above the health bar.
- Optionally only show it on enemies.
- Sits high enough to clear Overpower Plates' icon if you use both.
- Full settings page under Options > AddOns, with an entry on the minimap's addon button.

## Commands

| Command | What it does |
|---|---|
| `/tarrow` | Open settings |
| `/tarrow colour <red, yellow, green, blue, white>` | Arrow colour |
| `/tarrow size <n>` | Arrow size |
| `/tarrow offset <n>` | Height above the health bar |
| `/tarrow bob` | Turn bobbing on or off |
| `/tarrow enemies` | Only show on enemies |
| `/tarrow help` | All commands |

## Good to know
- The arrow attaches to nameplates, so it needs nameplates switched on (V for enemies).
- Your target needs to have a nameplate showing for the arrow to appear.
